# モザイク・タイル（Mosaic Tiles）

しきつめて あそぼう ― 三角形と四角形をマス目にしきつめて、もようを作る Web ツールです。

## 起動方法

`index.html` をブラウザで開くだけで動きます（1ファイル・外部ライブラリなし・ビルド不要・オフライン可）。
iPad の Safari、Chrome / Edge で動きます。タブレットの横向きを優先して作り、たて向きでは「上：ずけい／中：キャンバス／下：ボタン」の並びに切り替わります。

スマホ（画面の幅が600px以下）では、マス目をできるだけ広く使えるように、ボタンを画面の下から引き出す「シート」にしています。

- ふだんは、取っ手と「まわす・もどす・けしごむ・いろ」のボタンだけを表示します
- 取っ手を上にスワイプするか、「いろ・ほか」を押すと、ほかのボタンが出ます。下にスワイプするか、マス目をさわるとしまいます
- シートの中のボタン（色、パターンづくりなど）を押すと、自動でしまいます

## あそびかた

| やりたいこと | そうさ |
|---|---|
| ずけいを出す | 左の「ずけい」からドラッグ（タップすると画面の真ん中に出る） |
| 動かす・えらぶ | ずけいをドラッグ／タップ（点線でかこまれる） |
| まわす | 「まわす」（三角形は90度ずつ4通り、長方形はたて・よこ）。なにも選んでいないときは部品置き場の向きが変わる |
| いろ | いろをえらぶ（選んでいるずけいの色が変わり、次に出す色にもなる） |
| けす | 部品置き場にドロップ／「けしごむ」でタッチ（なぞっても消せる）／「ぜんぶけす」（確認あり） |
| もどす | 「ひとつもどす」（Ctrl/⌘+Z でも可） |
| 画面を動かす | 何もないところをドラッグ、二本指でピンチ、ホイール、＋／－／「ぜんたい」 |
| パターン | 「パターンづくり」→ まどの中にならべる →「くりかえし」で範囲をなぞる／「フラクタル」→「もういちど」 |
| 画像にする | 「ほぞんする」→ 背景色・文字・ペン →「がぞうを ほぞん」または「ながおしで ほぞん」 |

作っているもよう、パターンまど、マス目・枠線の状態、書き出しの設定は自動で localStorage に保存されます。

## 実装報告

### 描画方式：SVG（編集画面）＋ Canvas（書き出し）

- **編集画面は SVG**。図形1つ＝`<polygon>` 1つなので、タップされた図形の判定はブラウザに任せられます。三角形の空いている半分をタップしたときも正しく「背景」になります。拡大縮小しても線がにじまず、ゴースト・選択の点線・範囲表示も要素を足すだけで描けます。フラクタル最大（数千個）でも、変更時にまとめて描き直す方式で十分な速さでした。
- **書き出しは Canvas**。図形データから Canvas に描き直すので、マス目や選択表示は最初から入りません。ペンや文字の合成、高解像度の PNG（短辺1200px以上）の作成も簡単です。ペンは書き出し画面でしか使わないため、Canvas 上に置きました。

### 枠線あり／なしの印象

- **なし（初期値）**：同じ色の正方形2つが長方形に見え、三角形2枚は正方形に見えます。「しきつめたらひとつの形になる」ことがよく伝わり、完成したもようもきれいです。SVG の隙間（白い筋）は、図形と同じ色の細い線（0.8px）でふちを塗って防いでいます。
- **あり**：1枚1枚の区切りが見えるので、「何枚使ったか」「どこに三角形があるか」を数える・確かめる学習にはこちらが向いています。ただし、もようとしては線が目立ってうるさくなります。
- 結論として初期値は「なし」のままがよく、確かめたいときだけ「あり」にする使い方がよいと思います。書き出し画像にもこの設定が反映されます。

### マス目を消したときの背景色

薄いグレーと白を比べ、**白**にしました。グレーのままだと「まだ作業中」に見えますが、白にするとすぐに「作品」らしく見えます。白い図形が見えにくくなるので、必要ならいつでも「ますめ」でグレー＋線に戻せます。

### パターン機能：見送った点・簡略化した点

- **大きい図形・長方形もパターンまどに置けます**。まどに収まれば「くりかえし」で使えます。「フラクタル」は小さい正方形・三角形だけのときに使え、それ以外のときはメッセージを出します。
- **フラクタルの置き場所は、画面の中央に自動で置きます**（範囲指定はしない）。場所を変えたいときは、画面を動かしてから押します。
- フラクタルは、1回目に押したときが第2段階（n²×n²）、「もういちど」で第3段階（n³×n³、最大64×64マス）です。第1段階はまどの中身そのものなので省きました。
- 「もういちど」は、フラクタルを作った直後だけ押せます。ほかの操作をしたり「ひとつもどす」で戻したりしたあとは押せなくなります。
- フラクタルの警告は、画面に全部入れると1マスが9px未満になるとき、または図形が3000個を超えるときに確認を出します。広がったもようは自動で全体が見えるように縮小します。
- 1つのマスに補い合う三角形2枚が入っている場合も、フラクタルでは「図形が置かれたマス」として扱い、最後の段階には2枚ともコピーします。

### 自分で判断した点

1. **しきつめ画面の広さ**：100×100マスで固定しました。フラクタル最大の64×64マスも収まります。
2. **重なったときの押し出し**：半径8マス以内で、一番近く置ける位置を探します。回転して重なるときは半径3マス以内で探し、なければ「ここでは まわせないよ」と出して回しません。
3. **回転の基準**：長方形を回すときは、左上の角を固定して回します。真ん中を中心に回すと半マスずれてしまうためです。
4. **何も選ばずに「まわす」**：部品置き場の三角形・長方形の向きを変えます。同じ向きの三角形をたくさん並べるときに便利です。
5. **部品置き場をタップ**：ドラッグが苦手な子のために、タップで画面の真ん中（空いている所）に出せるようにしました。
6. **「ぜんぶけす」**：しきつめ画面だけを消し、パターンまどの中身は残します。確認ダイアログにもそう書いてあります。マス目は自動で ON に戻ります。
7. **「ひとつもどす」**：しきつめ画面とパターンまどで共通の1本の履歴です（最大60回）。マス目の表示は、パターン作成とぜんぶけすを取り消したときだけ元に戻します。手でマス目を切り替えた分まで「もどす」で巻き戻ると、混乱するためです。
8. **パターンまど**：画面右上に浮かぶ小窓で、見出しの部分をドラッグすると動かせます。まどの図形はしきつめ画面へ、しきつめ画面の図形はまどへ、ドラッグで移せます。
9. **書き出しの文字**：自由に置ける位置は「うえ／した」と「ひだり／まんなか／みぎ」の組み合わせにしました。こうすると文字が必ずもようの外側に出て、画像の範囲も自動で決められます。大きさは3段階で、もようの大きさに合わせて変わります。
10. **ペンの消しゴム**：線の一部ではなく、さわった線を1本まるごと消す方式です。「もどす」「ぜんぶ」（確認あり）も付けています。
11. **画像の大きさ**：短辺1200px、長辺は最大4096pxです。
12. **確認ダイアログ**：ブラウザ標準の `confirm` ではなく、大きなボタンの自作ダイアログにしました（iPad でも見やすくするため）。
13. **キーボード**（大人向け）：Ctrl/⌘+Z でもどす、R でまわす、Delete で選んだ図形を消す、Esc でモードを解除。
